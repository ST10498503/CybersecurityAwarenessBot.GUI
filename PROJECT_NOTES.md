# Project Notes

## Project Overview
The Cybersecurity Awareness Assistant is a C# WPF desktop application designed to help users learn about online safety through interactive conversations.

## Main Features
- Keyword recognition for cybersecurity topics.
- Randomised security tips.
- Follow-up prompts to continue a conversation.
- Session-based user name and favourite topic memory.
- Sentiment detection with supportive responses.
- Audio greeting and ASCII logo support.
- A graphical chat interface.

## Technologies
- C#
- .NET 8
- Windows Presentation Foundation (WPF)
- XAML
- GitHub for source control and project releases
- GitHub Actions for automated builds

## Running the Application
Open the solution in Visual Studio 2022, select the WPF GUI project as the startup project, and run it on Windows.

## Important
The application should be tested on the target computer before submission. Actual test results should be recorded in `TESTING.md`.
